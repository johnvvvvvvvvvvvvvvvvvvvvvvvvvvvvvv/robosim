# معمارية RoboSim

## الحزم واتجاه الاعتماد
```
core  ←  render   (Three.js؛ لا يعتمد على sim، يقرأ أي BodyStateSource)
core  ←  sensors  ←  api
core  ←  sim   (Rapier داخل Worker، لا يعتمد عليه إلا sim)
core, api, render  ←  ui
all  ←  apps/web
```
- `core`: العقود (types/interfaces) والبروتوكول. **لا يعتمد على أي حزمة ولا على DOM.**
- قاعدة: لا اعتماد دائري، ولا تعتمد `core` على غيرها أبداً.

## خيوط التنفيذ
| الخيط | المسؤولية |
|---|---|
| Main | الواجهة وإدارة الـWorkers |
| Sim Worker | الفيزياء + الحساسات + استدعاء المتحكم |
| Render (Main أو OffscreenCanvas) | الرسم فقط، يقرأ الحالة من SharedArrayBuffer |
| Controller Worker | كود المستخدم المعزول (مع مهلة تنفيذ) |

## الوحدات
- المسافة: متر. الزاوية: راديان. الزمن: ثانية. المحاور: Y لأعلى، نظام يميني.

## الذاكرة المشتركة
Seqlock بدون أقفال: الكاتب (Sim) يزيد `sequence` لرقم فردي، يكتب، ثم يزيده لزوجي.
القارئ يعيد المحاولة إن كان التسلسل فردياً أو تغيّر أثناء القراءة. التفاصيل في `core/src/protocol.ts`.

## الحتمية
`seed` ثابت + خطوة زمنية ثابتة + ترتيب ثابت لتحديث الأجسام والحساسات = نتائج متطابقة.

## استضافة
Cloudflare Workers Static Assets. الترويسات `COOP: same-origin` و`COEP: require-corp` **إلزامية**
وتُضبط في `apps/web/public/_headers`. التفاصيل في `docs/CLOUDFLARE.md`.

## المرحلة 1: التفاصيل
- `RapierWorld` ينفذ `World` فوق Rapier (نسخة deterministic). يُستورد داخل الـWorker فقط.
- `FixedStepClock`: تراكم زمن حقيقي ← عدد صحيح من الخطوات (مع حد أقصى لمنع دوامة الموت).
- `SharedStateWriter/Reader`: Seqlock. الخانة الفارغة = NaN. الأجسام الثابتة والنائمة لا تُعاد كتابتها.
- `SimClient`: واجهة الخيط الرئيسي (إنشاء Worker، إضافة أجسام، تحكم بالسرعة، إحصاءات).
- اللقطة (snapshot): `[uint32 طول][JSON meta][لقطة Rapier]` وتشمل خرائط المعرفات والخانات.
- الصفحة التجريبية ترسم مسقطاً جانبياً ثنائي الأبعاد للتحقق فقط.

## المرحلة 2: التفاصيل
- `SceneRenderer`: Three.js + `InstancedMesh` (استدعاء رسم واحد لكل نوع شكل: صندوق/كرة/أسطوانة).
- **الاستيفاء:** يحتفظ بآخر لقطتين ويرسم بينهما بحسب الزمن منذ وصول الأحدث (تأخير بمقدار فاصل واحد)،
  مع slerp للدوران. عند التوقف المؤقت يثبت العرض على آخر لقطة.
- **الجودة التلقائية** (`AdaptiveQuality`): 5 مستويات (pixelRatio وحجم خريطة الظل). تخفيض بعد ~1.5ث من fps < 45،
  ورفع بعد ~8ث من fps ≥ 57، مع فترة تهدئة.
- **الأجسام الثابتة** لا تُحدَّث بعد أول رسم. الأرضية (plane) كائن عادي + شبكة (GridHelper).
- **الكاميرا:** حرة (OrbitControls) أو تتبع جسم بنعومة.
- WebGPU وOffscreenCanvas: تُفحص فقط وتُؤجَّل لمرحلة التحسين (8) إن لزم.
